Funzioni di MineScript

Usa le funzioni per leggere il progresso, scrivere nella console e creare raccolte. Per minare, chiama mine() sulla GPU che vuoi usare.

Come leggere i comandi

Le parentesi contengono i valori da passare alla funzione. Se sono vuote, non serve alcun valore. Un risultato restituito può essere salvato in una variabile o usato in una condizione.

Controllare il programma

Controlla il progresso

progress()

Restituisce la percentuale del blocco attivo, da 0 a 100. Il valore può avere decimali. Usalo nella condizione di un ciclo per fermarti quando il blocco è completo.

Scrivi nella console

print(valore)

Mostra un valore nella console: testo, numero o risultato di una funzione. Usa + per unire testo e numeri in un unico messaggio.

Fai una pausa

wait(ms)

Attende da 0 a {{ balance.scripting.maxWaitMs }} millisecondi. Per esempio, wait(1000) attende un secondo.

Durante la pausa il mining non avanza. La velocità 2× non riduce questa attesa.

Quando raggiungi il 100%

Ricevi il premio in BTC simulati, meno la bolletta accumulata, una sola volta per blocco. La chiamata successiva a gpu.mine(), oppure un nuovo avvio del programma, prepara il blocco seguente. Rig e GPU rimangono gli stessi.

Scegliere una raccolta di dati

Usa un vettore per leggere e modificare valori in qualsiasi posizione. Usa una pila o una coda per decidere in quale ordine recuperare i vettori. Ogni raccolta può contenere al massimo 1000 elementi.

Vettore: una lista di valori

vector()

Crea una lista vuota e modificabile. Leggi un elemento con [0]; gli indici partono da zero e arrivano a length - 1.

Leggere, modificare e cercare valori

Chiama i metodi dopo il nome del vettore e un punto. Gli attributi si leggono nello stesso modo, ma senza parentesi.

length / size
Numero di elementi. Sono attributi, senza parentesi.
first / last
Primo e ultimo valore; restituiscono null se la lista è vuota.
get(indice)
Legge il valore nella posizione indicata, come le parentesi quadre.
push(valore)
Aggiunge in fondo e restituisce il nuovo numero di elementi.
pop()
Toglie e restituisce l'ultimo valore; restituisce null se la lista è vuota.
set(indice, valore)
Sostituisce un valore esistente e restituisce il valore inserito. Usa questo metodo per modificare una posizione.
insert(indice, valore)
Inserisce nella posizione indicata e sposta avanti gli elementi successivi. Restituisce la nuova lunghezza; l'indice può essere uguale a length per aggiungere in fondo.
remove(indice)
Toglie e restituisce il valore indicato. Gli elementi successivi scalano di una posizione.
contains(valore)
Restituisce true se il valore è presente, altrimenti false.
indexOf(valore)
Restituisce l'indice della prima occorrenza, oppure -1 se il valore manca.
concat(vettore)
Restituisce un nuovo vettore con gli elementi di entrambi, nello stesso ordine.
slice(inizio, fine)
Restituisce un nuovo vettore dalla posizione iniziale inclusa a quella finale esclusa. I due indici devono essere tra 0 e length, con fine maggiore o uguale a inizio.
copy()
Crea un nuovo vettore con gli stessi elementi. Eventuali vettori contenuti restano condivisi.
reverse() / sort()
Modificano il vettore e lo restituiscono: il primo inverte l'ordine, il secondo ordina in senso crescente. sort() richiede solo numeri oppure solo stringhe.
clear() / isEmpty()
Il primo svuota la lista. Il secondo restituisce true se è vuota, altrimenti false.

Un indice fuori intervallo interrompe il programma con un errore.

Pila: recupera l'ultimo inserito

stack()

Crea una pila vuota. Accetta solo vettori: l'ultimo che inserisci è il primo che recuperi, come in una pila di piatti.

Inserire e recuperare vettori dalla pila
push(vettore)
Aggiunge in cima e restituisce il nuovo numero di vettori.
pop() / peek()
Leggono il vettore in cima. pop() lo toglie, peek() lo lascia nella pila. Se è vuota, restituiscono null.
size / length
Numero di vettori presenti. Sono attributi, senza parentesi.
isEmpty() / clear()
Il primo restituisce true se la pila è vuota, altrimenti false. Il secondo la svuota.

Coda: recupera il primo inserito

queue()

Crea una coda vuota. Accetta solo vettori: li recuperi nello stesso ordine in cui li inserisci, come in una fila alla cassa.

Inserire e recuperare vettori dalla coda
enqueue(vettore)
Aggiunge in fondo e restituisce il nuovo numero di vettori.
dequeue()
Toglie e restituisce il primo vettore; restituisce null se la coda è vuota.
peek() / front() / back()
Leggono senza togliere: i primi due il vettore in testa, il terzo quello in fondo. Se la coda è vuota, restituiscono null.
size / length
Numero di vettori presenti. Sono attributi, senza parentesi.
isEmpty() / clear()
Il primo restituisce true se la coda è vuota, altrimenti false. Il secondo la svuota.

null significa che non c'è un valore. Pile e code conservano i vettori inseriti: modificare un vettore modifica anche quello presente nella raccolta.

let gpu = plots[0].rig(0).gpu(0);
gpu.mine();
print("Progresso: " + progress());

gpu.mine() aggiorna la scena. wait() aggiunge una pausa facoltativa.

Gestire la GPU

Una GPU è la scheda che esegue il mining. Dal programma puoi leggere se è disponibile, quanto consuma e come cambiano temperatura e ventole. Puoi impostare la frequenza, controllare l'usura e fermarla.

Trovare una scheda nella farm

La farm è divisa in {{ plotCapacity }} plot, cioè aree. Ogni area contiene {{ rigsPerPlot }} rig, le strutture che ospitano le schede. Ogni rig ha {{ gpusPerRig }} slot GPU, per un totale di {{ gpuCapacity }} posti. 

let gpu = plots[0].rig(0).gpu(0);
  1. plots[0] sceglie la prima area. Indici validi: da 0 a {{ plotCapacity - 1 }}.
  2. .rig(0) sceglie il primo rig di quell'area. Indici validi: da 0 a {{ rigsPerPlot - 1 }}.
  3. .gpu(0) sceglie il primo slot di quel rig. Indici validi: da 0 a {{ gpusPerRig - 1 }}.

Gli indici partono da zero; gli identificativi id partono da uno. Puoi anche usare plots[0].rig(0).gpus[0].

GPU disponibili all'inizio: {{ balance.world.startingGpuCount }}

Sono sbloccati {{ balance.world.startingRigCount }} rig e {{ balance.world.startingGpuCount }} GPU. Puoi leggere anche gli slot bloccati, ma non usarli per minare. Lo sblocco di altri rig e GPU non è ancora disponibile.

Minare con questa GPU

mine() è un metodo della GPU. gpu.mine() fa lavorare solo la scheda indicata. Ogni chiamata aggiunge {{ balance.world.progressPerGpuAtFullFarm }}/{{ gpuCapacity }}% al blocco attivo alla frequenza di base ({{ balance.gpu.mining.frequencyGhz }} GHz) e attende che il lavoro finisca prima di proseguire. Il progresso cresce in proporzione alla frequenza impostata. 

gpu.mine();

Alla frequenza di base servono {{ minesPerBlock }} chiamate a gpu.mine() per completare un blocco. Ogni chiamata dura {{ balance.mining.actionDurationMs }} ms, oppure {{ balance.mining.actionDurationMs / 2 }} ms a velocità 2×. La GPU e il rig devono essere sbloccati. Usa progress() per sapere quando fermare il ciclo.

Identità e stato

Identificare la scheda

gpu.id, gpu.rigId e gpu.plotId identificano scheda, rig e plot.

gpu.type restituisce GPU.

Sapere se può minare

gpu.unlocked indica che GPU e rig sono sbloccati. gpu.working e gpu.isWorking() richiedono anche assenza di stop e usura inferiore al 100%.

Attenzione al nome: working indica la disponibilità, non un mining in corso.

Sapere se è selezionata

gpu.selected e gpu.isSelected() indicano la selezione corrente: true per la GPU selezionata con un clic, false per le altre. Il trasferimento al banco richiede un doppio clic.

Modello

Restituisce il nome della scheda: {{ idleGpu.model }}.

Attributo: gpu.model

Frequenza, consumo e raffreddamento

Ogni scheda ha stato e telemetria propri. Frequenza e potenza salgono solo sulla GPU che mina; temperatura e usura crescono con il lavoro. A riposo la scheda raffredda in {{ balance.gpu.cooldownMs }} ms, ma l'usura resta. Non misurano l'hardware del tuo computer. I valori sotto descrivono il profilo base: l'overclock li modifica.

Puoi leggere ogni dato con un metodo, che usa le parentesi, oppure con il relativo attributo, senza parentesi. Entrambi restituiscono lo stesso valore al momento della lettura.

Impostazioni e telemetria

Gli attributi sono di sola lettura. Per cambiare frequenza usa setFrequencyGhz(); consumo, calore e ventole vengono calcolati automaticamente. I comandi sulla GPU restituiscono null; i getter restituiscono numeri, salvo modello e motivo di stop (stringhe).

Overclock e limiti

Impostare la frequenza

gpu.setFrequencyGhz(2.1);

Accetta un numero finito in GHz, almeno {{ balance.gpu.limits.minFrequencyGhz }}. Valori più bassi o di tipo errato producono un errore senza modificare la scheda. Si usa tra due chiamate a mine(), anche su una GPU ferma.

Più GHz aumentano il progresso in proporzione e la potenza al quadrato del rapporto con la frequenza base. Oltre il massimo del modello aumenta il rischio di surriscaldamento. A {{ balance.gpu.limits.temperatureCelsius }} °C la GPU va in stop: l'azione che causa il guasto consuma corrente e usura, senza assegnare progresso.

Leggere i limiti del modello

gpu.getMinFrequencyGhz()

Minimo: {{ balance.gpu.limits.minFrequencyGhz }} GHz. Attributo: minFrequencyGhz.

gpu.getMaxFrequencyGhz()

Massimo nominale: {{ balance.gpu.limits.frequencyGhz }} GHz. Attributo: maxFrequencyGhz.

gpu.getAbsoluteMaxFrequencyGhz()

Limite assoluto incluso: {{ balance.gpu.limits.absoluteFrequencyGhz }} GHz. Attributo: absoluteMaxFrequencyGhz. Un tentativo superiore attiva lo stop e conserva l'ultima frequenza valida. Questo limite non garantisce una temperatura sicura.

gpu.getTargetFrequencyGhz()

Frequenza impostata, conservata anche a riposo o in stop. Attributo: targetFrequencyGhz. getFrequencyGhz() indica invece quella attuale: {{ balance.gpu.idle.frequencyGhz }} GHz a riposo, zero in stop.

Usura e stop persistente

Leggere l'usura

gpu.getWearPercent()

Numero da 0 (nuova) a 100 (esaurita), attributo wearPercent. Il lavoro aumenta l'usura; overclock e temperature alte la accelerano. Raffreddamento, stop e nuova esecuzione non la azzerano. Al 100% la scheda non può più minare; nel prototipo si ripristina solo con una nuova partita.

Fermare e riabilitare

gpu.stop(); gpu.isStopped() gpu.getStopReason() gpu.clearStop();

stop() è ripetibile e mantiene la GPU ferma tra le esecuzioni. isStopped() restituisce un booleano (attributo stopped); getStopReason() restituisce il motivo o una stringa vuota (attributo stopReason).

clearStop() rimuove lo stop senza avviare il mining: serve poi mine(). Fallisce se la GPU è ancora troppo calda o esaurita. Abbassare la frequenza da solo non annulla lo stop.

Stop e riabilitazione della GPU si comandano solo dal codice, con gpu.stop() e gpu.clearStop(). Gli script sono sequenziali: una chiamata a mine() termina prima di eseguire la riga successiva. Il pannello Corrente e GPU mostra le specifiche della scheda selezionata nel rig. Il pulsante Stop dell'editor interrompe il programma senza impostare lo stop della GPU: l'azione interrotta conserva energia e usura parziali, senza progresso o premio.

gpuCount conta le GPU utilizzabili, con scheda e rig sbloccati. gpuCapacity conta tutti gli slot, anche quelli bloccati. Le raccolte plots, rigs e gpus sono di sola lettura.

Numero totale di rig ({{ rigsPerPlot }}), GPU utilizzabili e slot totali ({{ gpusPerPlot }}).

Identificativi del rig e dell'area a cui appartiene. Il tipo vale rig.

true se il rig è sbloccato, false altrimenti.

Il vettore degli slot GPU e il metodo per sceglierne uno per indice.

Numero di GPU utilizzabili e slot totali ({{ gpusPerRig }}).

Costrutti del linguaggio

Le variabili conservano valori, le condizioni scelgono cosa eseguire e i cicli ripetono le istruzioni. Combinandoli puoi automatizzare il mining.

Regole fondamentali

  • Termina ogni istruzione semplice con ;.
  • Racchiudi il corpo di un ciclo o di una condizione tra { }.
  • In parallel scrivi un comando semplice per riga. Si avviano insieme e il programma prosegue quando hanno finito tutti.
  • Scrivi // per aggiungere un commento: il resto della riga viene ignorato.

Conservare e aggiornare un valore

Una variabile associa un nome a un valore. Creala con let; usa = per assegnarle un valore nuovo.

let obiettivo = 100; obiettivo = obiettivo - 20; let i = 0; i++;

++ aumenta di uno; -- diminuisce di uno. Le variabili valgono per tutta l'esecuzione, anche fuori dal blocco in cui sono dichiarate, e si azzerano al prossimo avvio. Un altro let con lo stesso nome ne sostituisce il valore.

Valori disponibili e nomi delle variabili
  • Numeri: interi o decimali, scritti con il punto.
  • Stringhe: testo tra virgolette singole o doppie.
  • Booleani: true (vero) e false (falso).
  • Valore assente: null.
  • Raccolte: vettori, pile e code, descritte in Funzioni.
  • Oggetti della farm: plot, rig e schede, descritti in GPU.

Nei nomi usa lettere da A a Z, cifre e _, senza iniziare con una cifra. Maiuscole e minuscole sono diverse. Dichiara una variabile prima di usarla.

Ripetere un numero preciso di volte: repeat

Usalo quando sai già quante ripetizioni servono. Accetta un numero intero da 0 a 1000.

repeat (5) { ... }

Il corpo viene eseguito cinque volte. Con zero ripetizioni viene saltato.

Ripetere finché serve: while

Usalo quando devi raggiungere un risultato, come completare il blocco attivo.

while (progress() < 100) { ... }

Controlla la condizione prima di ogni ripetizione. Se è falsa, il ciclo termina; se è già falsa all'inizio, il corpo non viene eseguito.

Il corpo deve far avanzare il lavoro: qui serve gpu.mine(). Leggere il progresso o aspettare non lo fa aumentare.

Ripetere con un contatore: for

Usalo quando vuoi conoscere il numero della ripetizione o scorrere una raccolta.

for (let i = 0; i < 5; i++) { ... }
  1. let i = 0 crea il contatore una sola volta.
  2. i < 5 decide se eseguire il corpo, prima di ogni ripetizione.
  3. i++ aggiorna il contatore dopo il corpo.

Il corpo viene eseguito cinque volte, con i da 0 a 4.

Avviare più comandi insieme: parallel

Prepara una variabile per ogni GPU, poi metti un comando per riga. Partono tutti nello stesso momento; il programma aspetta che abbiano finito prima di continuare. 

let gpuUno = plots[0].rig(0).gpu(0);
let gpuDue = plots[0].rig(0).gpu(1);

parallel {
  gpuUno.mine();
  gpuDue.mine();
}

Usa una volta sola ogni GPU nel blocco.

Scegliere cosa eseguire: if e else

if esegue il suo blocco quando la condizione è vera. else esegue l'alternativa quando è falsa; puoi ometterlo.

if (progress() == 100) { ... } else { ... }

== confronta due valori; = assegna un valore a una variabile. Sono operazioni diverse.

Calcolare e confrontare valori

+ - * / %

Somma, sottrazione, moltiplicazione, divisione e resto della divisione. + unisce i valori come testo se uno dei due è una stringa. Dividere per zero, anche con %, causa un errore.

== != < <= > >=

Uguale, diverso, minore, minore o uguale, maggiore, maggiore o uguale. Restituiscono true oppure false. I confronti di ordine richiedono numeri; == e != confrontano anche il tipo, senza convertire testo in numero.

&& || !
  • && significa “e”: entrambe le condizioni devono essere vere.
  • || significa “o”: basta che una condizione sia vera.
  • ! significa “non”: inverte il valore della condizione.

Usa le parentesi tonde per rendere esplicito l'ordine dei calcoli e dei confronti.

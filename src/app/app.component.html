Funzioni built-in

Queste funzioni sono disponibili direttamente in ogni programma MineScript.

mine();

Estrae il 20% del banco selezionato. Al completamento assegna 0,0100 BTC simulati; il premio si riceve una sola volta.

progress();

Restituisce il progresso del banco selezionato, da 0 a 100. Puoi usarlo nelle condizioni dei cicli.

print(valore);

Mostra un numero, una stringa o un valore nella console. Usa + per unire testo e numeri.

wait(ms);

Attende il numero di millisecondi specificato. Intervallo ammesso: da 0 a 5000.

Un esempio

mine();
print("Progresso: " + progress());

Ogni chiamata a mine() aggiorna la scena; wait() aggiunge una pausa facoltativa.

Costrutti del linguaggio

Combina variabili, condizioni e cicli per decidere come lavora la GPU.

Variabili e valori

let obiettivo = 100; obiettivo = obiettivo - 20; let i = 0; i++;

Valori disponibili: numeri, stringhe e booleani. Le variabili valgono per tutta l'esecuzione e si azzerano al prossimo avvio.

Ripetizioni

repeat (5) { ... } while (progress() < 100) { ... } for (let i = 0; i < 5; i++) { ... }

repeat esegue un numero fisso di volte; while ripete finché la condizione è vera; for combina inizializzazione, condizione e aggiornamento.

Condizioni

if (progress() == 100) { ... } else { ... }

Usa if per scegliere quale blocco eseguire, con else facoltativo.

Operatori e commenti

+ - * / % == != < <= > >= && || !

Gli operatori logici combinano condizioni. Scrivi // per iniziare un commento; termina ogni istruzione semplice con ;.
